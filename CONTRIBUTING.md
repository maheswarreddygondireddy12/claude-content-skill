# Contributing

Thanks for helping improve this reusable video editing workflow.

- Keep instructions adaptable to different audiences, brands, platforms, and editing styles.
- Document commands and behavior that are supported by the implementation. Mark estimates and limitations clearly.
- Do not add personal videos, voice recordings, screenshots, logos, finished exports, credentials, local paths, model caches, or private project metadata.
- For stock or audio assets, include provenance, licence, and attribution details. Do not assume an asset is cleared because it is downloadable.
- Keep examples synthetic and generic. Use relative paths and environment variables for local configuration.
- Run the public package check and the pipeline tests before submitting changes.

Describe user-facing changes and any platform/model/licence assumptions in the pull request.
